# 内置风格样板

默认选一张并查看，再作为图片参考传入生成工具。用户只需描述角色，不需要上传图片；这仍然是 `bundled-reference`（使用内置参考图）模式，不是完全无图生成。

| 文件 | 用途 |
| --- | --- |
| [baker.png](baker.png) | 圆软帽、紧凑工作服、短围裙，适合炼金术士、厨师、工匠等 |
| [postman.png](postman.png) | 短夹克、裤装和小包，适合邮差、商人、旅行者等 |
| [florist.png](florist.png) | 短发、围裙和裙装，适合花匠、店员等 |

按服装轮廓选择，不限制角色性别、肤色或身份。样板用于保持比例、明暗色块与像素密度；用户描述中的新服装、发型和道具优先。模板没有要求复制样板角色。

这些是此前迭代中由内置图像生成工具生成、经用户认可画风的原创职业角色，设计阶段曾使用用户提供的游戏画面裁切作为画风参考。因此它们不是纯文字生成证明。仓库不分发那张游戏画面或裁切。三个 PNG 保留生成输出，没有缩小、限色或平滑处理。具体文件哈希见 `provenance.json`。
