# 画风规范

描述性名称：**柔和圆润的日式 Q 版地图像素风**，英文可用 **cozy JRPG overworld character sprites**。`16-bit`、`hi-bit pixel art` 只是辅助关键词，不能代替下面的造型和色块要求。

## 固定的视觉语言

| 部位 | 目标 | 常见偏差 |
| --- | --- | --- |
| 整体比例 | 约两头身；头发或帽子形成饱满大轮廓，约占总高的 45–50% | 三四头身、细长四肢、头像加小身体 |
| 脸 | 露出的脸小；眼睛是简短深色像素，鼻嘴极简且位置清楚，年龄服从角色描述 | 大眼、虹膜高光、睫毛、精细五官、把腮红画成鼻孔般的中央双点 |
| 身体 | 肩窄、脖子不明显、短躯干、短手短腿、厚实小鞋 | 宽肩、长脖子、长腿、尖细手脚 |
| 视角 | 轻微俯视的四分之三正面，能看见少量帽顶和鞋面 | 正面立绘、平视人像、强透视 |
| 轮廓 | 深褐色描边，短而连贯的像素阶梯，圆团组合的外形 | 锯齿噪点、尖薄转折、粗黑框、平滑矢量曲线 |
| 色块 | 连贯的底色与少量明确阴影簇；暖色中间调塑造体积 | 碎像素、随机颗粒、密集抖色、复杂衣褶 |
| 光照 | 柔和统一的上方偏左光照，亮部克制，颜色明快协调 | 空气笔渐变、塑料反光、发光边、强轮廓光 |

圆润来自**轮廓和色块塑形**。阴影可以细腻，但各块颜色之间仍应有明确边界；少量有意安排的过渡色不等于对整张图做模糊。不要把“像素风”解释成任意加颗粒或套马赛克滤镜。

## 五官与年龄

- 对人类角色，鼻子在小地图尺度可以省略，或用一小块低对比肤色阴影表示；需要嘴时，用位于眼睛下方的一条短暖褐色线或小弧表示。默认不加腮红；用户要求时放在两侧外脸颊，避免在鼻嘴中央形成两个高饱和红点。样板中的面部色点不属于必须继承的画风特征。
- 两头身不等于幼童脸。明确要求老人时，保留小脸和像素密度，从低垂或微眯的眼睑、稀疏眉毛、少量眼角或笑纹色块、略松弛的脸颊、轻微含胸姿态中选两三项表达年龄。白发或发髻不能单独承担年龄辨识；不用密集写实皱纹，也不自动增加眼镜、拐杖等道具。

## 细节密度与输出尺寸

默认按一名小镇地图人物的阅读尺度设计：从头顶到鞋底，视觉细节密度大致相当于 **46–50 个逻辑像素**，主体约 **30–35 个逻辑像素宽**。这些数字是提示词中的尺度参照，不是生成器实际输出尺寸，也不是原生网格验证结果。

大尺寸生成图应像小精灵的放大预览，不应因画布大就添加发丝、衣缝、手指和细密装饰。输出可能是带像素外观的高分辨率 PNG；未经网格整理和验证，不称为可直接导入引擎的原生 48×48 精灵。

不要通过强制缩成 32×32、粗暴限色、锐化或模糊来“修正”画风。若用户明确要求原生尺寸或固定调色板，先以该约束重新安排可读的轮廓与细节，并如实说明仍需人工精修的地方。

## 可以变化的内容

- 职业、发型、肤色、年龄感、服装主色、表情和小道具服从用户描述。
- 未指定时选简单站姿、清晰服装分区和一个能辨认职业的小道具；没有道具需求时不必强加。
- 复杂职业通过一两处标志性形状表达，不依靠满身装备。道具不能遮住大半身体。
- 不把新角色的服装、身份或肤色锁成前一个示例；锁定的是造型语言。

## 看图时检查什么

先看透明 PNG 的放大图，再看接近地图使用大小的预览。缩放预览采用最近邻；检查原图时也应保留原始文件。

1. 小尺寸仍看得出职业、主色与道具，头身比例紧凑。
2. 脸是小脸，眼睛没有抢走帽子、头发与衣服的视觉重心；在小尺寸下仍能看出所要求的年龄，鼻嘴与腮红不会混成含义不清的中央双点。
3. 曲线由清楚的阶梯和连贯色块构成，没有逐渐变成光滑插画。
4. 阴影有温暖中间色，但没有糊掉的轮廓和大面积镜面亮斑。
5. 全身完整、留有空边，透明区域是真实 alpha；没有画出来的棋盘格、地板或额外人物。

默认使用 Skill 内置的一张风格样板；按 [样板索引](../assets/style-anchors/README.md) 选择并显式传入工具。它提供比例和色块参考，角色身份仍由用户描述决定。明确记录图片用途和实际使用情况，这种运行不能标为纯文字测试。用户指定不使用任何图片时，改为纯文字模式，不读取样板或历史图片。

## 后续动画的保真约束

本 Skill 的当前交付重点是静态角色。若继续开发动画，以用户认可的静态图作为不可变母版，每个姿态从母版或已批准的部件派生，不连续重绘上一帧。预览关闭平滑插值；像素部件位移使用整数坐标，避免亚像素运动。真正的走路、转身仍需要逐帧设计与检查，单纯移动整张图不能算完成这些动作。
